# Third-party notices

Lanboat's desktop interface uses Fego, and its networking engine uses Lanboat All-in-One. Releases include the available license texts for bundled dependencies.

The routing data comes from [zatxm/geoip](https://github.com/zatxm/geoip). The bundled fallback data credits and licenses are in `COPYING.geoip-data` and `COPYING.sing-geoip`. Lua compatibility files are covered by `COPYING.shadowrocket-lua`.

The Linux desktop app uses the system X11 library.

Country flags are rendered from Google's Noto Color Emoji font. Its notice is included in the installer.
